# Markdown 跳转链接显示修复

修复版本：0.3.1

Jina Reader 会把 Discourse 标题锚点输出成：

```markdown
## [](https://linux.do/t/topic/2795372#p-21902435-h-2)客户端支持
```

空链接没有可见标签，旧清洗器不会把它当作普通链接处理，后续标题转换便把完整 Markdown 语法显示在长图中。

0.3.1 在图片提取之后、标题和普通链接转换之前删除空标签链接。规则使用否定前瞻保护 `![](图片)`，因此不会误删空 alt 的 Markdown 图片；普通 `[标签](URL)` 仍保留标签和可读 URL。

验证覆盖：

- 主题 2795372 的三个真实标题锚点；
- 普通 GitHub 标签链接；
- 空目标及非 HTTP 目标；
- 空 alt Markdown 图片；
- 修复主题的完整长图视觉检查；
- 生产候选及活跃版本的 Reader、T2I、群聊、私聊和 OneBot JPEG 链路。

同时增加 T2I 文件头校验。若渲染服务把 `no available server` 等文本写成 `.jpg`，插件不会再缓存或发送该文件，而是返回已有的长图生成失败提示。
